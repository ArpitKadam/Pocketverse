# cheats-script

Per-engine script packs (RGSS, Ren'Py, MV/MZ) and the flag/trigger protocol for `.exe`-style games.

- **Type:** pure Kotlin/JVM library.
- **Package:** `com.pocketverse.cheats.script`. The module's public API lives in `com.pocketverse.cheats.script.api`; everything else is `internal`.
- **May depend on:** cheats-core, core-*. Enforced by `./gradlew checkModuleBoundaries`.
- **Status:** skeleton (P1-2). No code yet.
