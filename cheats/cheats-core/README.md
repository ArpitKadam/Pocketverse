# cheats-core

Canonical cheat model, storage, import/export for text, `.cht` and XML.

- **Type:** pure Kotlin/JVM library.
- **Package:** `com.pocketverse.cheats.core`. The module's public API lives in `com.pocketverse.cheats.core.api`; everything else is `internal`.
- **May depend on:** core-model, core-common, engine-api. Enforced by `./gradlew checkModuleBoundaries`.
- **Status:** skeleton (P1-2). No code yet.
