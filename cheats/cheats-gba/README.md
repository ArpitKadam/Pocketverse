# cheats-gba

Decoders for raw, GameShark, GameShark Advance v3, Action Replay and Code Breaker codes. See `docs/research/CHEAT_FORMATS.md`.

- **Type:** pure Kotlin/JVM library.
- **Package:** `com.pocketverse.cheats.gba`. The module's public API lives in `com.pocketverse.cheats.gba.api`; everything else is `internal`.
- **May depend on:** cheats-core, core-*. Enforced by `./gradlew checkModuleBoundaries`.
- **Status:** skeleton (P1-2). No code yet.
