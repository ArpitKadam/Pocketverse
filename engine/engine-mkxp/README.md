# engine-mkxp

RPG Maker XP/VX/VX Ace: Android port of mkxp-z plus our own Ruby shim pack.

- **Type:** Android library.
- **Package:** `com.pocketverse.engine.mkxp`. The module's public API lives in `com.pocketverse.engine.mkxp.api`; everything else is `internal`.
- **May depend on:** engine-api, engine-compat, core-*. Enforced by `./gradlew checkModuleBoundaries`.
- **Status:** skeleton (P1-2). No code yet.
